## PROJECT BRIEF
Nama project: whatsapp chat bot 
Deskripsi: ini adalah bot whatsapp yg kedepannya akan serba guna dan bisa di tambahkan beberapa fitur-fitur yg menarik menggunakan module Baileys untuk terhubung dengan whatsapp

## TECH STACK
Backend: nestJS
Database: PostgreSQL
Hosting target: docker pada vps
AI: antropic atau claude

## FITUR UTAMA
1. bisa menjawab dan melanjutkan obrolan serta dapat melakukan multiple bubble chat
2. terdapat beberapa tools simple sepeti melihat cuaca 
3. terapkan beberapa key comand seperti /reset untuk melakukan reset chat 

## FITUR YANG TIDAK PERLU (scope limit)
- chat hanya bisa dilakukan pada roomchat pribadi bukan grub dll
- tidak perlu generate gambar
